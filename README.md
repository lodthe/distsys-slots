# Запись на защиты

Telegram Mini App для записи на защиты домашних заданий. Открывается внутри
Telegram; бот присылает уведомления и напоминания.

- **Студент** выбирает свободный слот, записывается и может отменить запись.
- **Ассистент** создаёт окна приёма, смотрит список участников и отменяет защиты.
- **Администратор** добавляет ДЗ и разрешённые даты защит.

## Конфигурация

Для запуска нужен Linux с systemd и Docker Compose, а также публичный домен
с HTTPS, направленный на ваш сервер.
[Пример настройки Nginx](deploy/nginx/README.md).

Настройки и секреты задаются в `.env`, пример — [.env.example](.env.example):

- `TELEGRAM_BOT_TOKEN` — токен бота из `@BotFather`.
- `APP_BASE_URL` — HTTPS-адрес приложения.
- `POSTGRES_PASSWORD` — пароль базы данных.
- `TELEGRAM_WEBHOOK_SECRET` — случайный секрет от 32 символов для запросов Telegram.
- `ADMIN_TELEGRAM_USERNAME` — юзернейм первого администратора без `@` (необязательно).

## Назначение ролей

В запущенном приложении назначьте роли по Telegram ID или юзернейму:

```bash
docker compose exec app distsys grant-admin 123456789
docker compose exec app distsys grant-assistant @username
```

Остальные пользователи входят как студенты.
