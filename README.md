# Запись на защиты

Приложение внутри Telegram: администратор задаёт ДЗ и даты защит, ассистенты
добавляют свободное время, студенты записываются. Бот присылает уведомления
и напоминания.

## Что нужно

- Сервер с Docker и Docker Compose.
- Telegram-бот: создайте его через `@BotFather` и получите токен.
- Домен с HTTPS, который ведёт на ваш сервер.

Команды ниже выполняйте из папки проекта.

## Настройка

При первом запуске скопируйте пример настроек:

```bash
cp .env.example .env
chmod 600 .env
```

Откройте `.env` и заполните значения:

| Параметр | Что указать |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Токен вашего бота из `@BotFather`. |
| `APP_BASE_URL` | Адрес приложения, например `https://slots.example.com`, без пути после домена. |
| `POSTGRES_PASSWORD` | Пароль базы данных. Создайте командой `openssl rand -hex 32`. |
| `TELEGRAM_WEBHOOK_SECRET` | Секрет для проверки сообщений от Telegram. Ещё раз выполните `openssl rand -hex 32` и вставьте новое значение. |
| `ADMIN_TELEGRAM_USERNAME` | Telegram-юзернейм первого администратора, без `@`. Роль появится после его входа. Можно оставить пустым и назначить администратора командой ниже. |
| `HTTP_ADDR` | Оставьте как есть. При запуске через Docker Compose этот параметр не используется. |

`.env` содержит секреты. Не публикуйте его; файл уже исключён из Git.

## Запуск

Запустите приложение:

```bash
docker compose up -d --build
```

Docker сам создаст хранилища для данных, логов и резервных копий, запустит базу
и создаст в ней нужные таблицы. Настраивать права на папки не нужно. Первый запуск
рассчитан на пустую БД; перенос со старых версий схемы не поддерживается.

Проверьте, что приложение работает:

```bash
curl --fail http://127.0.0.1:8083/readyz
```

Подключите домен по [инструкции настройки HTTPS](deploy/nginx/README.md).
Она направляет запросы с вашего домена на приложение по адресу `127.0.0.1:8083`.
После этого настройте бота:

```bash
docker compose exec app distsys configure-bot
```

Команда подключит уведомления от Telegram и добавит кнопку открытия приложения
в меню бота. Откройте чат с ботом и запустите приложение через эту кнопку.

## Администраторы и ассистенты

Назначить роль можно по Telegram ID или юзернейму, даже до первого входа:

```bash
docker compose exec app distsys grant-admin 123456789
docker compose exec app distsys grant-assistant @username
```

Замените ID и юзернейм на реальные. Остальные пользователи входят как студенты.
Администратор сначала добавляет ДЗ и даты, затем ассистенты создают окна записи.

## Полезные команды

```bash
docker compose logs --tail=100 app    # Посмотреть логи приложения
docker compose down                  # Остановить; данные БД сохранятся
docker compose up -d --build         # Запустить снова или обновить код
docker compose run --rm backup once  # Сделать резервную копию сейчас
docker compose cp backup:/backups ./ # Скопировать резервные копии в ./backups
```

Резервные копии создаются автоматически раз в сутки. Они и логи хранятся
в постоянных томах Docker и сохраняются при пересоздании контейнеров.
Старые файлы автоматически не удаляются. Не используйте `docker compose down -v`,
если хотите сохранить данные: эта команда удалит и базу, и логи, и бэкапы.

Если раньше использовались папки `backups/` и `logs/` на сервере, старые файлы
останутся в них; новые будут записываться в Docker-тома.

Ссылки на репозитории студентов настроены для `https://distsys.ru/hse-2026/`.
Для другого курса измените этот адрес в `internal/app/auth.go` и
`internal/app/web/app.js`.
